# Результат работы: 2026-10-12 (Москва)

## Что найдено

Исходный pavel, commit 9055ba9: README, SavedBot placeholder и архивный HTML. Торговых агентов, API, состояния арены, deployment-файлов, настроек домена/SSH нет. origin/main совпадал с локальной версией. arena.kpd100.site и публичный Coinbase API недоступны из этой среды (HTTP CONNECT 403). Учётных данных сервера и VPN нет. Не обходили политику доступа.

## Что реализовано

- Отдельный пакет `arena`, SavedBot сохранён. Только виртуальные USD/BTC, три отличающиеся стратегии VECTOR/ORBIT/PULSE на завершённых дневных ценах, анализ ticker каждые 30с. Для ожидания сохраняется конкретное объяснение.
- Размер позиции по доле капитала и риску на сделку; стоп, цель, максимальный срок, комиссии и проскальзывание на обе стороны. Цена исполнения учитывает bid/ask. Просадка от high-water mark, постоянный halt и ликвидация при первой свежей котировке после превышения. Гэпы исполняются по наблюдаемой цене.
- SQLite WAL/FULL, атомарный цикл и журнал, lease одного worker, дедупликация котировок, устойчивость к перезапуску, backoff/jitter/timeout. Невалидные и устаревшие данные блокируют торговлю. Будущая версия БД не перезаписывается старым кодом.
- Read-only API и worker отдельными процессами. Диагностика успешного цикла, heartbeat, запуска, свежести, свечей, ошибок и retry. `/live` отдельно от `/health` (readiness).
- Адаптивная арена: рейтинг, график капитала, доходность/просадка/комиссии, открытые позиции, стоп/цель, объяснения решений, правила стратегии, фильтр журнала, отчёт на истории и прозрачное состояние системы. При API error сохраняется последняя информация с явной пометкой потери связи.
- Docker Compose с non-root образом, постоянным volume, restart policy и healthchecks; альтернативные systemd units и пример location для существующего HTTPS vhost. Без pip-зависимостей в приложении. CI для backend/browser/report/image.
- Реальные Coin Metrics PriceUSD, pinned Git revision, SHA256 и атрибуция. Исходные данные 2022-01-01 — 2026-05-23; прогрев 40 наблюдений; оценка 2022-02-10 — 2026-05-23. Один движок для live/backtest, исторические данные в живую БД не импортируются.

## Что осталось и как продолжить

**arena.kpd100.site НЕ обновлён, реальная работа worker 24/7 НЕ подтверждена.** Нет доступа к существующему серверу/конфигурации, сеть запрещает production/рынок. Все доступные локальные проверки выполнены; дальнейшая работа требует среды с разрешённым доступом к этому серверу и публичным Coinbase endpoints.

Точный план в `docs/OPERATIONS.md`: изучить текущий vhost/сервис, backup, checkout проверенной ветки, запустить один постоянный volume и отдельные процессы, проверить свежий `/health`, подключить существующий HTTPS vhost, проверить внешний домен/mobile, закрытие сайта/API и перезапуск сервера; настроить мониторинг и наблюдать минимум сутки. Не переносить fixture-БД и не подключать реальные ордера. Если приоритет — улучшение стратегий: сначала добавить разрешённые реальные Coinbase OHLC/внутридневные данные и walk-forward проверку; не обещать прибыль и не подгонять параметры под этот единственный тест.
