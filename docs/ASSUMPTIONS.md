# Решения и ограничения

- В исходном pavel (9055ba9) нет торговой арены, серверного кода, deployment-файлов или конфигурации arena.kpd100.site. Сохраняем SavedBot и добавляем отдельный пакет `arena`.
- В среде нет серверных учётных данных; HTTP CONNECT к arena.kpd100.site и api.exchange.coinbase.com отвечает 403. Не обходим сетевую политику. Публичный GitHub доступен.
- Только виртуальные USD, по $10 000 на каждого из трёх агентов. Spot BTC-USD, только long, без плеча и реальных ордеров. В коде нет обменных ключей, SDK ордеров или торговых POST-запросов.
- Разные стратегии на закрытых дневных ценах; worker анализирует свежий ticker каждые 30 секунд для защиты позиции. Новые входы не требуют сделок для активности. После сделки на дневной свече второй вход на ней запрещён.
- Источник живых котировок: публичный Coinbase Exchange BTC-USD, ticker и завершённые свечи 86400с. Котировка старше 60с, время из будущего, спред >2%, незакрытая свеча, пропуск истории или устаревшая история блокируют весь цикл, включая виртуальные выходы. При недоступном рынке нельзя обещать исполнение стопа.
- Комиссия 0,1% и проскальзывание 0,05% на каждую сторону — консервативные модельные допущения, не фактический тариф аккаунта. Live-покупка от ask, продажа от bid. Все P&L включают комиссии. Капитал позиции — оценка ликвидации по bid с выходными издержками.
- Риск на сделку определяет бюджет вместе с лимитом доли капитала. Гэп может превысить стоп и лимит просадки: исполняем по наблюдаемой цене, не придумываем цену стопа. Достигнутый лимит просадки фиксируется в БД и запрещает новые входы; автоматического сброса нет.
- SQLite WAL на локальном постоянном диске, `synchronous=FULL`. Весь цикл всех агентов, журнал сделок, отметки обработанных котировок и капитал коммитятся одной транзакцией. DB lease 120с защищает от нескольких worker; котировки дополнительно дедуплицируются транзакционно. SQLite не подходит для нескольких серверов с сетевым диском.
- Worker и HTTP API — разные процессы. Браузер ничего не запускает. Docker restart policy и systemd обеспечивают перезапуск; постоянный volume обязателен. Это подготовленный способ запуска, а не подтверждённый production.
- История: Coin Metrics community `PriceUSD`, pinned Git revision и SHA256 в `data/history_source.json`, 2022-01-01 — 2026-05-23. 40 наблюдений прогрева, затем сигнал только по предыдущим наблюдениям, исполнение на следующем. Параметры не оптимизировались по результатам.
- Справочная дневная цена не равна Coinbase OHLC или исполнимой цене. Исторический спред неизвестен; внутридневные стопы/цели не проверены. В тесте защитные выходы наблюдаются раз в день; в live раз в 30с. Бэктест — ограниченная проверка правил, не доказательство live-доходности.
- Benchmark вкладывает все $10 000 в BTC в начале оцениваемого периода и ликвидирует в конце с теми же комиссиями/проскальзыванием. Стратегии используют меньшую экспозицию и остановку по риску; доходность нельзя сравнивать без просадки.
- Живая БД не заполняется историческими или тестовыми сделками. Пустые графики остаются пустыми до работы worker. Бэктест показан отдельно.
- Капитал сохраняется почасово (последнее наблюдение часа), год в БД; UI получает последние 1000 точек на агента. Полный журнал сделок сохраняется, UI получает последние 100. Ошибки: последние 100 в БД, 10 в UI. Все максимальные просадки рассчитываются на каждом обработанном ticker, а не по прореженному графику.
